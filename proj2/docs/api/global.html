rankUsers(users) → {Array.<object>}

Ranks users by computeScore(), descending, with a deterministic tie-break (ascending userId) so equal scores always come out in the same order. Pure function: no Firestore access, no I/O. Does not mutate its input; returns new objects with `score` and `rank` (1-indexed) attached. Every element of `users` must have a `userId` -- that's the identity ranking is keyed on, unlike the computeScore fields (which default to 0 when missing).

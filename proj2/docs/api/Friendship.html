(async) accept() → {Promise.<Friendship>}

Flips this friendship's status to `accepted` and sets `acceptedAt`, both in Firestore and on this instance. Caller is responsible for checking that the status is currently `pending` and that the caller isn't the original requester (see server/routes/friends.js `POST /accept`).

(async, static) create(params) → {Promise.<Friendship>}

(async, static) listForUser(userId) → {Promise.<Array.<Friendship>>}
